# Computer Graphics

计算机图形学课程作业：使用现代 OpenGL 实现日地月运动模型，并逐步加入纹理与光照。

> 当前状态：项目初始化，尚未实现动画程序，也尚未提供截图或可执行文件。

## 作业目标

### 作业一：日地月运动模型

- 使用 OpenGL 3.3 或更高版本。
- 地球绕太阳运动，月球绕地球运动，运动关系正确、相对速度合理。
- 地球公转轨道与月球绕地轨道不共面。
- 轨道可采用圆形或椭圆形。

### 作业二：纹理与光照

- 在作业一的基础上增加球体纹理，至少为地球提供纹理贴图。
- 将场景主光源设置在太阳位置。
- 如有需要，可增加专门照亮太阳的侧后方辅助光源。

每份作业的交付目标均为：源代码、实际运行截图、包含所需运行依赖及资源的可执行包。

## 技术方向

计划采用 C++、CMake、GLFW 和 OpenGL Core Profile，保持源码跨平台。

- **macOS**：主要开发与运行验证平台。已在 Apple M1 Max 上创建 OpenGL 4.1 Core 上下文，查询得到 OpenGL `4.1 Metal - 90.5`、GLSL `4.10`。
- **Windows**：计划额外提供可双击运行的发行包，需在 Windows 上编译和验证；macOS 可执行文件不能直接在 Windows 上运行。

构建说明将在程序实现并验证后补充。天体尺寸、轨道距离和动画时间尺度将以教学可视性为目标，并明确说明与真实比例的区别。
